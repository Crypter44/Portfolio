01Robotum — Advanced Project

Project Hestia

An autonomous, self-operating kitchen

Hestia's long-term vision is a kitchen that cooks, cleans, and operates itself — while still leaving room for a human to cook fully by hand whenever they want to. It's an advanced project under Robotum and still in its early stages: so far we've built working prototypes of the mobile base with a custom differential drive and AprilTag-based navigation, and developed collision-free manipulation planning for a Franka Emika arm, shown in the clip.

Franka Emika Panda Motion Planning Differential Drive AprilTag Navigation Early-Stage R&D
02Team Project — ROS2

Autonomous Systems Challenge

A drone that explores caves on its own

A ROS2 software stack for a UAV that autonomously explores and maps an unknown cave system — finding landmarks and recording their positions without a human at the controls. My focus was the exploration logic and path planning that decide where the drone flies next. The clip above is the point cloud being built live, sped up; the stills show the finished reconstruction.

ROS2 SLAM Path Planning Point-Cloud Mapping UAV
03Personal Project — Android

Reversi

A Minimax AI you can actually lose to

A native Android build of the classic strategy game Reversi (Othello). The interesting part is the opponent: a Minimax algorithm with alpha-beta pruning, with several board-evaluation heuristics implemented and compared against each other for playing strength and search depth.

Kotlin Android Minimax Alpha-Beta Pruning Game AI

04Personal Project — Machine Learning

A neural network library, built from scratch

A from-scratch neural network library in Python, inspired by libraries like PyTorch but built for understanding rather than convenience — covering the full loop of building, training, and evaluating a network. The clip is a small classifier learning its decision boundary live, epoch by epoch.

05Personal Project — Infrastructure

Home Server

Self-hosted infrastructure, REST API included

A Python backend exposing a REST API, paired with a companion Android client built in Material 3 for remote control. Athena, the dashboard above, is the day-to-day control panel sitting on top — keeping an eye on the storage array, system load, and the small constellation of self-hosted services (DNS, SSO, media library, backups) running on the box.

About

Who's

I'm a first-year M.Sc. student in Robotics, Cognition, Intelligence at the Technical University of Munich, after finishing a B.Sc. in Computer Science at TU Darmstadt with a final GPA of 1.4. My bachelor's thesis looked at decentralized control of urban water distribution networks using multi-agent reinforcement learning.

Across the projects on this page — drone path-planning, game-tree search, from-scratch deep learning, and self-hosted infrastructure — the common thread is software that has to make its own decisions: robotics, machine learning, and the backend systems that hold it all together.
